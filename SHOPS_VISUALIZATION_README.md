# Отображение магазинов - Реализованный функционал

## Обзор

Реализована двойная система отображения магазинов в проекте:
1. **Сеточное представление (Grid View)** - классическая таблица с магазинами
2. **Визуальное представление (Visual View)** - интерактивное SVG отображение с возможностью редактирования

## Компоненты

### 1. ShopsVisualView.vue
Основной компонент для визуального отображения магазинов.

**Функциональность:**
- Отображение магазинов в виде прямоугольников на SVG холсте
- Цветовая кодировка статусов:
  - Зеленый (#69cf4f) - доступный
  - Желтый (#faed62) - зарезервированный
  - Оранжевый (#cc6140) - броне (продан)
- Поддержка фонового изображения (чертеж)
- Масштабирование (zoom) с помощью колеса мыши
- Перетаскивание (drag & drop) магазинов
- Изменение размера (resize) с 8 точками управления
- Поддержка сложных форм (многоугольники) с возможностью редактирования вершин (перетаскивание вершин, добавление новых clic&lt;ctrl&gt;)
- Переключение между прямоугольной и полигональной формами
- История изменений (undo/redo)
- Клавиша Shift при перетаскивании фиксирует перемещение по горизонтали или вертикали для точного позиционирования
- Автоматическое сохранение координат при редактировании

**Props:**
```typescript
- shops: Shop[] - массив магазинов
- projectId: string - ID проекта
- blockId: string - ID блока
- isEditing?: boolean - режим редактирования
```

**Events:**
```typescript
- selectShop(id: string) - при выборе магазина
- updateCoordinates(coords: ShopCoordinates) - при изменении координат
```

### 2. ShopCoordinatesEditor.vue
Компонент для редактирования координат магазина вручную.

**Функциональность:**
- Редактирование X, Y координат
- Редактирование ширины (Width)
- Редактирование высоты (Height)
- Синхронизация с визуальным представлением

### 3. ProjectBlockView.vue (обновлен)
Главный компонент с интеграцией обоих режимов отображения.

**Новая функциональность:**
- Переключатель между видами (Таблица / Визуально)
- Кнопка редактирования в визуальном режиме
- Отображение редактора координат при выборе магазина в режиме редактирования

## Модели данных

### Shop (src/models/shop.ts)
```typescript
interface Shop {
    id: string
    float: number
    name: string
    client: string
    reserved: boolean
    broned: boolean
    coordinates?: ShopCoordinates
}

interface ShopCoordinates {
    id: string
    type?: 'rect' | 'polygon'
    x?: number
    y?: number
    width?: number
    height?: number
    points?: Array<{ x: number; y: number }>
    rotation?: number
}
```

## Требуемые API endpoints

### GET /api/project/{projectId}/block/{blockId}/shops/coordinates
Получение координат всех магазинов блока.

**Response:**
```typescript
ShopCoordinates[]
```

### POST /api/project/{projectId}/block/{blockId}/shop/{shopId}/coordinates
Сохранение координат магазина.

**Body:**
```typescript
ShopCoordinates
```

### GET /api/project/{projectId}/block/{blockId}/blueprint
Получение фонового изображения (чертежа) блока.

**Response:** 
```
image/png или image/jpeg
```

## Использование

### Переключение между видами
```vue
<button @click="shopsViewMode = 'grid'">Таблица</button>
<button @click="shopsViewMode = 'visual'">Визуально</button>
```

### Включение режима редактирования (только в визуальном виде)
```vue
<button @click="isEditingShops = !isEditingShops">
    {{ isEditingShops ? 'Закончить' : 'Редактировать' }}
</button>
```

### Взаимодействие
- **Просмотр**: Клик по магазину открывает его деталь (переход на RoomView)
- **Редактирование**: 
  - Клик для выделения магазина
  - Перетаскивание для перемещения
  - Перемещение курсора к краям для изменения размера
- Клавиша Shift при перемещении или изменении размера ограничивает направление

## Технические особенности

1. **Масштабирование SVG**: Координаты преобразуются с учетом масштаба
2. **Grid фон**: Визуальная сетка для облегчения позиционирования
3. **Limit constraint**: Магазины не могут выходить за пределы холста
4. **Динамическая загрузка координат**: При загрузке, если координаты отсутствуют, они генерируются автоматически

## Стилизация

Все стили используют SCSS и находятся в соответствующих компонентах.

### Цветовая схема
- Доступный магазин: #69cf4f (зеленый)
- Зарезервированный: #faed62 (желтый)
- Проданный (броне): #cc6140 (оранжевый)
- Выделенный: #1e90ff (синий)
